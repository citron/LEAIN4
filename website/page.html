Chapitre 16 — Outils mathématiques : probabilité finie, entropie, KL

En bref (TL;DR)

En bref. Les pertes de ce cours se construisent à partir de trois quantités : espérance, entropie, divergence KL. Nous les définissons exactement (sur les rationnels), prouvons les faits que tout le monde cite — l'entropie d'un événement certain est 000, entropie croisée === entropie +++ KL, et l'inégalité de Gibbs KL(p∥q)≥0\mathrm{KL}(p\|q)\ge 0KL(p∥q)≥0 — et exécutons les mêmes formules en Float pour voir où s'arrête l'exactitude.

Mots nouveaux, en termes simples:

  • Distribution: Une liste de poids positifs dont la somme vaut 1 — les chances de chaque issue.
  • Espérance: La moyenne pondérée d'une quantité sous une distribution : « en moyenne, qu'est-ce que je gagne ? »
  • Variance: La distance quadratique moyenne à la moyenne : l'étalement d'une quantité.
  • Entropie: La surprise moyenne d'un tirage dans une distribution. Un événement certain ne surprend personne : entropie 0.
  • Entropie croisée: La surprise moyenne de la vraie distribution notée avec une distribution modèle. L'entraînement la minimise.
  • Divergence KL: La surprise supplémentaire due au code du modèle au lieu du vrai. Toujours ≥0\ge 0≥0 ; égale à 000 exactement quand les deux coïncident.
  • Inégalité de Gibbs: KL(p∥q)≥0\mathrm{KL}(p\|q) \ge 0KL(p∥q)≥0 : aucun modèle ne prédit jamais les données aussi bien que les données se prédisent elles-mêmes.

Les chapitres 3, 6, 9 et suivants minimisent tous une perte en entropie croisée, les chapitres 11 et 13 mesurent des distances entre distributions avec la KL, le chapitre 15 punit les plongements effondrés avec une variance. À chaque fois nous avons cité une propriété — « l'entropie croisée vaut au moins l'entropie », « la KL est positive » — sans la prouver. Ce chapitre paie ces dettes : il est la boîte à outils que le reste du cours suppose en silence.

Le chapitre est aussi un tournant méthodologique. Dès ici, tout scalaire d'un théorème est un Rat — un rationnel exact, le modèle dans lequel ce cours prouve (comme l'algèbre du perceptron du chapitre 2 le fait déjà). Les distributions sont finies, sur n points : assez pour toutes les pertes du cours, et assez petit pour qu'une « somme » n'exige aucune analyse — pas de limites, pas d'intégrales, pas d'epsilon-delta. Ce que les théorèmes disent est exactement vrai dans ce modèle ; les expériences en Float ne le satisfont qu'à l'arrondi près, et la démo imprime l'écart.

Les distributions, exactement​

Core/Prob.lean
/-- A probability distribution on `n` points: weights that are all strictly
positive and sum to `1`. Strict positivity keeps `log` of every weight
defined; the cases with zero weights are measure-theoretic bookkeeping, not
ideas, and we say so rather than hand-wave them. -/
structure Dist (n : Nat) where
  w : Vec Rat n
  pos : ∀ i, 0 < w i
  sum1 : Vec.dot w (fun _ => 1) = 1

Une Dist n est un vecteur de poids w : Vec Rat n avec deux champs : chaque poids est positif (pos), et les poids somment à 1 (sum1, écrit comme produit scalaire avec le vecteur de tous les 1). Le champ n est un nombre au niveau des types : une distribution sur 4 issues est un type différent d'une distribution sur 5 — une incompatibilité de taille est une erreur de type, pas un plantage à l'exécution.

Le logarithme est la seule pièce d'analyse du chapitre, et nous ne faisons pas semblant de le construire : LawfulLog est une opération abstraite à lois nommées (le même style que LawfulExp dans le noyau d'algèbre) :

Core/Prob.lean
/-- An abstract logarithm on `Rat`, with the four laws this course uses:
multiplication becomes addition, inverses become negation, and the
fundamental tangent inequality `log x ≤ x - 1`. The real logarithm satisfies
all four; `Float` satisfies them only up to rounding, which is exactly why
the statements are over exact `Rat` and not over `Float`. -/
class LawfulLog where
  log : Rat → Rat
  log_mul : ∀ x y, 0 < x → 0 < y → log (x * y) = log x + log y
  log_inv : ∀ x, x ≠ 0 → log x⁻¹ = -log x
  log_le : ∀ x, 0 < x → log x ≤ x - 1

/-- `log 1 = 0`, from `log_mul`: `log 1 = log (1·1) = log 1 + log 1`. -/
theorem log_one [LawfulLog] : LawfulLog.log (1 : Rat) = 0 := by
  have := LawfulLog.log_mul (1 : Rat) 1 (by grind) (by grind)
  grind

/-- `log x - log y = log (x / y)` for positive `x, y`: bookkeeping from
`log_mul` and `log_inv` (over `Rat`, `x / y` *is* `x * y⁻¹`). -/
theorem log_div [LawfulLog] {x y : Rat} (hx : 0 < x) (hy : 0 < y) :
    LawfulLog.log x - LawfulLog.log y = LawfulLog.log (x / y) := by
  have hyi : 0 < y⁻¹ := Rat.inv_pos.mpr hy
  show LawfulLog.log x - LawfulLog.log y = LawfulLog.log (x * y⁻¹)
  rw [LawfulLog.log_mul x y⁻¹ hx hyi, LawfulLog.log_inv y (by grind)]
  grind

Quatre lois : la multiplication devient addition, les inverses deviennent négation, et l'inégalité tangente log⁡x≤x−1\log x \le x - 1logx≤x−1, égalité seulement en 111. Tout théorème du chapitre vaut pour toute structure obéissant à ces lois. Le logarithme réel les obéit — c'est un théorème d'analyse, hors de ce cours — et Float ne les obéit qu'à l'arrondi près, ce qui est exactement pourquoi les énoncés portent sur Rat.

Espérance et variance​

Core/Prob.lean
/-- The **expectation** of `f` under `p`: the weighted average `Σᵢ pᵢ fᵢ`. -/
def expect (p : Dist n) (f : Vec Rat n) : Rat :=
  Vec.dot p.w f

/-- The **variance** of `f`: the expectation of the squared deviation from
the mean. It measures the spread of `f` under `p`. -/
def variance (p : Dist n) (f : Vec Rat n) : Rat :=
  p.expect (fun i => f i * f i) - p.expect f * p.expect f

L'espérance est un produit scalaire avec les poids ; la variance est E[f2]−(Ef)2E[f^2] - (Ef)^2E[f2]−(Ef)2. Quatre lois viennent gratuitement du produit scalaire — constante, additive, monotone, et E[1]=1E[1] = 1E[1]=1 (la probabilité totale se conserve) :

Core/Prob.lean
/-- The mean of the constant `1` is `1`: total probability is conserved. -/
theorem expect_one (p : Dist n) : p.expect (fun _ => 1) = 1 := p.sum1

/-- Expectation is **additive**: `E[f + g] = E[f] + E[g]`. -/
theorem expect_add (p : Dist n) (f g : Vec Rat n) :
    p.expect (fun i => f i + g i) = p.expect f + p.expect g := by
  simp only [expect]
  exact Vec.dot_add_right _ _ _

/-- Expectation is **monotone**: `f ≤ g` pointwise implies `E[f] ≤ E[g]`. -/
theorem expect_le (p : Dist n) {f g : Vec Rat n} (h : ∀ i, f i ≤ g i) :
    p.expect f ≤ p.expect g := by
  simp only [expect]
  exact dot_mono p.w f g (fun i => Rat.le_of_lt (p.pos i)) h

/-- The mean of a constant is that constant. -/
theorem expect_const (p : Dist n) (c : Rat) : p.expect (fun _ => c) = c := by
  show Vec.dot p.w (fun _ => c) = c
  rw [dot_smul_const, p.sum1]
  grind

et le nom « variance » est justifié par la forme centrée :

Core/Prob.lean
/-- The **centered** form of the variance: `E[(f - Ef)²] = E[f²] - (Ef)²`.
The two definitions agree; the left side explains the name, the right side
is what the computer computes. -/
theorem variance_eq_centered (p : Dist n) (f : Vec Rat n) :
    p.variance f =
      p.expect (fun i => (f i - p.expect f) * (f i - p.expect f)) := by
  have hrew : Vec.dot p.w
        (fun i => (f i - Vec.dot p.w f) * (f i - Vec.dot p.w f))
      = Vec.dot p.w (fun i => f i * f i) - Vec.dot p.w f * Vec.dot p.w f := by
    rw [show (fun i => (f i - Vec.dot p.w f) * (f i - Vec.dot p.w f))
          = (fun i => f i * f i + (-(2 : Rat) * (Vec.dot p.w f * f i))
              + (Vec.dot p.w f * Vec.dot p.w f)) from by
          funext i; grind,
        Vec.dot_add_right, Vec.dot_add_right,
        Vec.dot_smul_right (-(2 : Rat)), Vec.dot_smul_right (Vec.dot p.w f),
        dot_smul_const p.w (Vec.dot p.w f * Vec.dot p.w f), p.sum1]
    generalize Vec.dot p.w (fun i => f i * f i) = Q, Vec.dot p.w f * Vec.dot p.w f = S
    grind
  simp only [variance, expect]
  exact hrew.symm

variance_eq_centered prouve que la définition de calcul égale le sens : l'écart quadratique moyen à la moyenne. Une constante a une variance 000 (exercice 3) : une quantité non aléatoire ne s'étale pas.

Entropie, entropie croisée, KL​

Trois quantités d'un seul motif (somme pondérée de logarithmes) :

  • H(p)=∑i−pilog⁡piH(p) = \sum_i -p_i \log p_iH(p)=∑i​−pi​logpi​ — entropie : surprise moyenne de p.
  • CE(p,q)=∑i−pilog⁡qi\mathrm{CE}(p, q) = \sum_i -p_i \log q_iCE(p,q)=∑i​−pi​logqi​ — entropie croisée : surprise des données p notées avec le modèle q. C'est ce que l'entraînement minimise.
  • KL(p∥q)=∑ipilog⁡(pi/qi)\mathrm{KL}(p \| q) = \sum_i p_i \log (p_i / q_i)KL(p∥q)=∑i​pi​log(pi​/qi​) — la surprise supplémentaire du code du modèle.

La première identité les relie :

Core/Prob.lean
/-- **Cross-entropy = entropy + KL.** Minimising `CE(p, q)` over `q` is
minimising `KL(p ∥ q)` — the entropy of the data is a constant the model
cannot change — and the gap can never go below zero. This is the theorem
behind every classifier in the course. -/
theorem crossEntropy_eq_entropy_add_kl (p q : Dist n) :
    p.crossEntropy q = p.entropy + p.kl q := by
  show Vec.dot p.w (fun i => -LawfulLog.log (q.w i))
      = Vec.dot p.w (fun i => -LawfulLog.log (p.w i))
        + Vec.dot p.w (fun i => LawfulLog.log (p.w i) - LawfulLog.log (q.w i))
  rw [← Vec.dot_add_right]
  congr 1; funext i; grind

Entropie croisée = entropie + KL. L'entropie des données ne dépend pas du modèle, donc minimiser l'entropie croisée revient exactement à minimiser la KL : ajuster le modèle, pas les données. Voilà pourquoi l'entropie croisée est la perte de classification, et non un choix décoratif.

Inégalité de Gibbs : KL ≥ 0​

Le théorème qui donne un sens à l'entraînement :

Core/Prob.lean
/-- **Gibbs' inequality: `0 ≤ KL(p ∥ q)`.** Two distributions can never have
negative divergence; coding with the wrong code always costs extra surprise.
This single fact is why minimising cross-entropy pushes a model toward the
data distribution, and why the loss has a floor.

*Proof, in words.* With the tangent inequality at `qᵢ · pᵢ⁻¹`:
`log qᵢ − log pᵢ = log(qᵢ · pᵢ⁻¹) ≤ qᵢ · pᵢ⁻¹ − 1 = (qᵢ − pᵢ) · pᵢ⁻¹`.
Weighting by `pᵢ` cancels the inverse (`pᵢ · pᵢ⁻¹ = 1`, exactly, over
`Rat`) and the sum telescopes: `Σ(qᵢ − pᵢ) = Σqᵢ − Σpᵢ = 1 − 1 = 0`.
`KL` is the negation of the weighted sum of the left-hand sides, so
`KL ≥ 0`. The tangent inequality is the whole content of the theorem;
everything else is finite bookkeeping.
-/
theorem kl_nonneg (p q : Dist n) : 0 ≤ p.kl q := by
  -- Exact cancellation pᵢ·pᵢ⁻¹ = 1 over Rat.
  have hc : ∀ i, p.w i * (p.w i)⁻¹ = 1 := fun i =>
    Rat.mul_inv_cancel _ (Rat.ne_of_gt (p.pos i))
  -- Step 1: pointwise bound  log qᵢ − log pᵢ ≤ (qᵢ − pᵢ) · pᵢ⁻¹.
  have hpoint : ∀ i, LawfulLog.log (q.w i) - LawfulLog.log (p.w i)
      ≤ (q.w i - p.w i) * (p.w i)⁻¹ := by
    intro i
    have hp : 0 < p.w i := p.pos i
    have hq : 0 < q.w i := q.pos i
    have hlog : LawfulLog.log (q.w i) - LawfulLog.log (p.w i)
        = LawfulLog.log (q.w i * (p.w i)⁻¹) := log_div hq hp
    have hpos : 0 < q.w i * (p.w i)⁻¹ := Rat.mul_pos hq (inv_pos' hp)
    have ht := LawfulLog.log_le (q.w i * (p.w i)⁻¹) hpos
    rw [hlog]
    refine Rat.le_trans ht ?_
    have hc0 := hc i
    grind
  -- Step 2: sum the bounds with weights pᵢ ≥ 0.
  have hS : Vec.dot p.w (fun i => LawfulLog.log (q.w i) - LawfulLog.log (p.w i))
      ≤ Vec.dot p.w (fun i => (q.w i - p.w i) * (p.w i)⁻¹) :=
    dot_mono p.w _ _ (fun i => Rat.le_of_lt (p.pos i)) hpoint
  -- Step 3: the right side telescopes to Σqᵢ − Σpᵢ = 1 − 1 = 0.
  have hzero : Vec.dot p.w (fun i => LawfulLog.log (q.w i) - LawfulLog.log (p.w i))
      ≤ 0 := by
    rw [dot_inv_telescope p.w q.w hc, q.sum1, p.sum1] at hS
    grind
  -- Step 4: KL is the negation of that sum; flip the bound.
  show 0 ≤ Vec.dot p.w (fun i => LawfulLog.log (p.w i) - LawfulLog.log (q.w i))
  have hflip : Vec.dot p.w (fun i => LawfulLog.log (p.w i) - LawfulLog.log (q.w i))
      = -(Vec.dot p.w (fun i => LawfulLog.log (q.w i) - LawfulLog.log (p.w i))) := by
    rw [show (fun i => LawfulLog.log (p.w i) - LawfulLog.log (q.w i))
          = (fun i => -(LawfulLog.log (q.w i) - LawfulLog.log (p.w i)))
            from by funext i; grind]
    exact dot_neg _ _
  rw [hflip]
  exact Rat.neg_le_neg hzero

La preuve est celle du manuel, entièrement vérifiée. La borne ponctuelle log⁡q−log⁡p≤(q−p)/p\log q - \log p \le (q-p)/plogq−logp≤(q−p)/p est l'inégalité tangente log⁡x≤x−1\log x \le x-1logx≤x−1 appliquée à x=q/px = q/px=q/p et réécrite avec log_div ; sommer contre des poids pi≥0p_i \ge 0pi​≥0 préserve l'inégalité (dot_mono) ; le côté droit télescope — ∑ipi(qi−pi)/pi=∑iqi−∑ipi=1−1=0\sum_i p_i (q_i - p_i)/p_i = \sum_i q_i - \sum_i p_i = 1 - 1 = 0∑i​pi​(qi​−pi​)/pi​=∑i​qi​−∑i​pi​=1−1=0 — via l'annulation exacte p⋅p−1=1p \cdot p^{-1} = 1p⋅p−1=1 qui vaut sur Rat et échoue sur Float ; nier retourne le signe. Quatre étapes, chacune une ligne de Lean.

Conséquences : la KL vaut 000 exactement quand p=qp = qp=q (l'inégalité tangente est stricte ailleurs qu'en 111) ; l'entropie croisée est bornée en dessous par H(p)H(p)H(p), il y a un plancher qu'aucun modèle ne bat ; et un modèle qui donne une probabilité quasi nulle à un événement qui se produit paie une perte quasi infinie — la ligne « sûre et fausse » de la démo.

Généralisation : biais, variance, et pourquoi les ensembles marchent​

Pourquoi un modèle qui colle parfaitement aux données d'entraînement échoue-t-il parfois sur des données nouvelles ? La réponse a une forme exacte — et ici c'est un théorème, pas un graphique. Tire une hypothèse d'une famille (le hasard de l'entraînement : ordre des données, graines, minibatchs), note chaque hypothèse sur chaque entrée contre la cible, fais la moyenne. L'identité :

\mathbb{E}_{k}\[(f_{k}(x)-t(x))^{2}\] = (\bar f(x)-t(x))^{2} + \mathbb{E}_{k}\[(f_{k}(x)-\bar f(x))^{2}\], \qquad \bar f(x) = \mathbb{E}_{k}\[f_{k}(x)\]

risque = biais au carré de la moyenne + variance de la famille. Aucune théorie des probabilités au-delà de deux sommes pondérées, pas de limites, pas d'asymptotique — c'est l'algèbre des moyennes, valable entrée par entrée :

Core/Prob.lean
/-- The **ensemble average** of a family of models `f : Fin m → Vec Rat n` (one
prediction per input) under the ensemble distribution `p` over hypotheses:
`f̄ i = Σₖ pₖ · fₖ i`. -/
def wavg {m n : Nat} (p : Dist m) (f : Fin m → Vec Rat n) : Vec Rat n :=
  fun i => Vec.dot p.w (fun k => f k i)

/-- **The average of the family is the ensemble mean**: `Σₖ pₖ fₖ i = f̄ i`. -/
theorem expect_f_eq_wavg {m n : Nat} (p : Dist m) (f : Fin m → Vec Rat n) (i : Fin n) :
    p.expect (fun k => f k i) = wavg p f i := by
  simp only [wavg, expect]

/-- A weighted sum of zeros is zero. -/
theorem dot_zero_fun {m : Nat} (w : Vec Rat m) :
    Vec.dot w (fun _ => (0 : Rat)) = 0 := by
  induction m with
  | zero => simp only [Vec.dot]; try grind
  | succ m ih =>
      have h := ih (fun i => w i.succ)
      simp only [Vec.dot]
      grind

/-- **The cross term vanishes**: the average deviation of the family from its own
mean is zero. -/
theorem wavg_dev_zero {m n : Nat} (p : Dist m) (f : Fin m → Vec Rat n) (i : Fin n) :
    p.expect (fun k => f k i - wavg p f i) = 0 := by
  simp only [expect]
  rw [dot_sub]
  have h1 : Vec.dot p.w (fun k => f k i) = wavg p f i := by
    have t := expect_f_eq_wavg p f i
    simp only [expect] at t
    exact t
  have h2 : Vec.dot p.w (fun _ => wavg p f i) = wavg p f i := by
    rw [dot_smul_const, p.sum1]
    grind
  rw [h1, h2]
  grind

/-- **Pointwise decomposition of the ensemble risk** at one input `x = i`, with
target `t i`: the mean squared error of the individual models equals the squared
bias of the average plus the (ensemble) variance:
`Σₖ pₖ (fₖ i − t i)² = (f̄ i − t i)² + Σₖ pₖ (fₖ i − f̄ i)²`. -/
theorem wavg_pointwise {m n : Nat} (p : Dist m) (f : Fin m → Vec Rat n) (t : Vec Rat n)
    (i : Fin n) :
    Vec.dot p.w (fun k => (f k i - t i) * (f k i - t i))
      = (wavg p f i - t i) * (wavg p f i - t i)
        + Vec.dot p.w (fun k => (f k i - wavg p f i) * (f k i - wavg p f i)) := by
  have hsq : (fun k => (f k i - t i) * (f k i - t i))
      = (fun k => (wavg p f i - t i) * (wavg p f i - t i)
          + (f k i - wavg p f i) * (f k i - wavg p f i)
          + (2 : Rat) * ((wavg p f i - t i) * (f k i - wavg p f i))) := by
    funext k
    grind
  have hcross : Vec.dot p.w (fun k => (wavg p f i - t i) * (f k i - wavg p f i)) = 0 := by
    rw [Vec.dot_smul_right (wavg p f i - t i)]
    have h : Vec.dot p.w (fun k => f k i - wavg p f i) = 0 := by
      have t := wavg_dev_zero p f i
      simp only [expect] at t
      exact t
    rw [h]
    grind
  have hconst : Vec.dot p.w (fun k => (wavg p f i - t i) * (wavg p f i - t i))
      = (wavg p f i - t i) * (wavg p f i - t i) := by
    rw [dot_smul_const, p.sum1]
    grind
  rw [hsq, Vec.dot_add_right, Vec.dot_add_right, Vec.dot_smul_right (2 : Rat), hcross, hconst]
  generalize (wavg p f i - t i) * (wavg p f i - t i) = X,
    Vec.dot p.w (fun k => (f k i - wavg p f i) * (f k i - wavg p f i)) = V
  rw [Rat.mul_zero, Rat.add_zero]

/-- Two functions that agree at every point have equal weighted sums. -/
theorem dot_congruent {n : Nat} (w : Vec Rat n) {f g : Vec Rat n} (h : ∀ i, f i = g i) :
    Vec.dot w f = Vec.dot w g := by
  congr 1
  funext i
  exact h i

/-- **The bias–variance decomposition of the ensemble risk.** Averaging the
pointwise identity over the input distribution `q` (inputs `i`, target `t i`,
hypotheses drawn from `p`):

`risk = (bias)² + variance`, where
`risk = Σᵢ qᵢ Σₖ pₖ (fₖ i − t i)²`, `(bias)² = Σᵢ qᵢ (f̄ i − t i)²`,
`variance = Σᵢ qᵢ Σₖ pₖ (fₖ i − f̄ i)²`.

This is exact algebra on `Rat`: no probability theory beyond the two weighted
sums, no analysis, no limits. What it buys: **the risk of a single draw is the
risk of the average plus the variance of the family** — averaging hypotheses
fights variance, and only the average can fight bias. -/
theorem ensemble_risk_decomp {m n : Nat} (p : Dist m) (q : Dist n)
    (f : Fin m → Vec Rat n) (t : Vec Rat n) :
    Vec.dot q.w (fun i => Vec.dot p.w (fun k => (f k i - t i) * (f k i - t i)))
      = Vec.dot q.w (fun i => (wavg p f i - t i) * (wavg p f i - t i))
        + Vec.dot q.w (fun i =>
            Vec.dot p.w (fun k => (f k i - wavg p f i) * (f k i - wavg p f i))) := by
  have hpoint : (fun i => Vec.dot p.w (fun k => (f k i - t i) * (f k i - t i)))
      = (fun i => (wavg p f i - t i) * (wavg p f i - t i)
          + Vec.dot p.w (fun k => (f k i - wavg p f i) * (f k i - wavg p f i))) := by
    funext i
    exact wavg_pointwise p f t i
  rw [hpoint, Vec.dot_add_right]

Le moteur tient en un raisonnement : développe (fk−t)2=(fk−fˉ+fˉ−t)2(f_k - t)^2 = (f_k - \bar f + \bar f - t)^2(fk​−t)2=(fk​−fˉ​+fˉ​−t)2, et le terme croisé 2(fˉ−t) E[fk−fˉ]2(\bar f - t)\,\mathbb{E}[f_k - \bar f]2(fˉ​−t)E[fk​−fˉ​] meurt car l'écart moyen à la moyenne est nul (wavg_dev_zero). Sommer l'identité ponctuelle contre la distribution des entrées donne ensemble_risk_decomp.

Ce que ça achète, exactement :

  • Moyenner des hypothèses combat la variance. Le risque d'un tirage est le risque de la moyenne plus la variance — la moyenne n'est jamais pire. Dropout, bagging, model soups et moyennes de checkpoints encaissent ce chèque ; le théorème explique pourquoi ils marchent.
  • Seule la moyenne combat le biais. Moyenner trois modèles sous-ajustés donne une moyenne sous-ajustée : le biais est l'écart fˉ−t\bar f - tfˉ​−t, et aucun moyennage de bruit ne le referme. Le sous-ajustement est un problème de capacité, pas de chance.
  • La variance est une propriété de la famille, le biais de la moyenne. Un entraînement à forte variance (peu de données, réseaux surparamétrés, taux d'apprentissage agressifs) gonfle le second terme ; les régularisateurs échangent surtout de la variance contre du biais — la décomposition est le livre de comptes.

Le dernier bloc de la démo calcule l'identité numériquement : trois modèles bruités autour d'une droite, et risque − (biais² + variance) affiche 0.000000 — l'identité exacte survit à l'arrondi.

Théorie de l'apprentissage : les trois atomes​

L'identité biais-variance explique comment une famille généralise. Trois faits exacts expliquent ce qu'aucun apprenant ne contourne. Ils vivent dans Core/Theory.lean, prouvés avec la même algèbre de poids finis que tout ce qui précède.

Atome 1 — l'union bornée. À poids positifs, une somme pondérée domine chacun de ses termes :

Core/Theory.lean
/-- **Union-bound atom.** With nonnegative weights, an expectation
dominates its head term: the total is at least any single weighted
loss. Iterating this over the class index is exactly how a
finite-class generalization bound "P(some hypothesis bad) ≤
Σₕ P(h bad) ≤ M·δ" is proved: the union bound *is* this inequality,
iterated. -/
theorem dot_ge_head {n : Nat} (w f : Vec Rat (n + 1))
    (hw : ∀ i, 0 ≤ w i) (hf : ∀ i, 0 ≤ f i) :
    Vec.dot w f ≥ w 0 * f 0 := by
  show w 0 * f 0 + Vec.dot (fun i => w i.succ) (fun i => f i.succ) ≥ w 0 * f 0
  have ht := dot_nonneg (fun i => w i.succ) (fun i => f i.succ)
    (fun i => hw i.succ) (fun i => hf i.succ)
  grind

Toute affirmation « avec probabilité ≥ 1 − M·δ, toute hypothèse de la classe est ε-bonne » est cette inégalité itérée sur la classe : l'événement mauvais est inclus dans la réunion des événements mauvais par hypothèse, et la mesure d'une réunion est au plus la somme des mesures. La taille M de la classe entre linéairement dans la borne — c'est pourquoi borner la taille (ou la capacité) d'une classe de modèles, c'est borner son risque.

Atome 2 — train = test pour une hypothèse fixée. Sous la loi de la pièce équitable, l'espérance est la simple moyenne :

Core/Theory.lean
/-- The **fair coin** on two labels: each label has weight `1/2`. -/
def coin : Dist 2 := by
  refine ⟨fun _ => (2 : Rat)⁻¹, fun _ => Rat.inv_pos.mpr (by decide), ?_⟩
  show (2⁻¹ : Rat) * 1 + ((2⁻¹ : Rat) * 1 + 0) = 1
  grind

/-- **Coin expectation.** Under the fair coin, the expectation of any
loss profile `f` is the average of its two values. Both roles -
"training point" and "test point" - are the same law `coin`, so a
hypothesis chosen *independently of the test point* has the same
expectation in both roles: the number computed is identical. The
generalization gap a held-out set measures is exactly the dependence
introduced by fitting. -/
theorem coin_expect_avg (f : Vec Rat 2) : coin.expect f = (f 0 + f 1) / 2 := by
  unfold Dist.expect coin
  show (2⁻¹ : Rat) * f 0 + Vec.dot (fun i => (2 : Rat)⁻¹) (fun i => f i.succ)
      = (f 0 + f 1) / 2
  have htail : Vec.dot (fun i => (2 : Rat)⁻¹) (fun i => f i.succ)
      = (2⁻¹ : Rat) * f 1 := by
    show (2⁻¹ : Rat) * f 1 + Vec.dot (fun (i : Fin 0) => (2 : Rat)⁻¹) (fun (i : Fin 0) => f i.succ.succ)
        = (2⁻¹ : Rat) * f 1
    unfold Vec.dot
    grind
  rw [htail, Rat.div_def]
  grind

Le nombre calculé pour « le point d'entraînement » et pour « le point de test » est le même nombre — tant que l'hypothèse est choisie indépendamment du point. L'écart de généralisation est créé entièrement par l'ajustement : dès que l'hypothèse dépend de l'échantillon, la symétrie est brisée, et mesurer cette rupture est le rôle d'un jeu de test conservé.

Atome 3 — No Free Lunch. Sous des étiquettes tirées uniformément, toute prédiction — déterministe ou randomisée — a une erreur 0-1 espérée exactement égale à 1/2 :

Core/Theory.lean
/-- The 0-1 loss of predicting `y` against a label drawn from the coin:
`err y i = 1` exactly when `y` differs from `i` (and `0` when it
matches), written exactly as `(y - i)²` on `{0, 1}`. -/
def err (y : Fin 2) : Vec Rat 2 :=
  fun i => ((y.val : Rat) - (i.val : Rat)) ^ 2

/-- **No Free Lunch, atom.** Under uniform labels, *every* prediction
has expected 0-1 error exactly `1/2`: no deterministic learner beats
chance on average over all labelings. -/
theorem nfl_coin (y : Fin 2) : coin.expect (err y) = 1 / 2 := by
  unfold Dist.expect coin
  show (2⁻¹ : Rat) * err y 0 + Vec.dot (fun i => (2 : Rat)⁻¹) (fun i => err y i.succ) = 1 / 2
  have htail : Vec.dot (fun i => (2 : Rat)⁻¹) (fun i => err y i.succ)
      = (2⁻¹ : Rat) * err y 1 := by
    show (2⁻¹ : Rat) * err y 1
        + Vec.dot (fun (i : Fin 0) => (2 : Rat)⁻¹) (fun (i : Fin 0) => err y i.succ.succ)
        = (2⁻¹ : Rat) * err y 1
    unfold Vec.dot
    grind
  rw [htail]
  cases y with
  | mk k hk =>
    have hkk : k = 0 ∨ k = 1 := by omega
    rcases hkk with rfl | rfl
    · show (2⁻¹ : Rat) * (((0 : Nat) : Rat) - 0) ^ 2
          + (2⁻¹ : Rat) * (((0 : Nat) : Rat) - 1) ^ 2 = 1 / 2
      grind
    · show (2⁻¹ : Rat) * (((1 : Nat) : Rat) - 0) ^ 2
          + (2⁻¹ : Rat) * (((1 : Nat) : Rat) - 1) ^ 2 = 1 / 2
      grind

/-- **No Free Lunch, randomized.** Mixing predictions by any
distribution `q` on the two labels: the expected error is a convex
combination of `1/2`s, so it is still exactly `1/2`. Randomness buys
nothing on average over labelings. -/
theorem nfl_coin_mix (q : Dist 2) :
    q.expect (fun y => coin.expect (err y)) = 1 / 2 := by
  have h : (fun y => coin.expect (err y)) = (fun _ => (1 / 2 : Rat)) := by
    funext y
    exact nfl_coin y
  rw [h, q.expect_const]

En moyenne sur tous les étiquetages des données, aucun apprenant ne bat le hasard. Chaque avantage montré sur des données réelles est emprunté à une hypothèse qui dit que les données ne sont pas adverses : régularité, faible dimension, structure partagée. Le théorème est l'énoncé formel de « il n'y a pas d'apprentissage sans hypothèse » — le biais inductif n'est pas un choix de conception, c'est le droit d'entrée.

Les traductions en probabilité élevée (Hoeffding, Chernoff) quantifient l'écart d'une moyenne empirique à son espérance par des exponentielles exp(-2nε²) ; ce sont des faits analytiques sur exp dans les réels. Sur Rat nous gardons les atomes exacts et nous disons sans détour où le pas exponentiel est pris — nous ne le cachons pas.

Ce qui est prouvé, et ce qui ne l'est pas

Prouvé, sur Rat avec un logarithme abstrait : EEE, la variance, HHH, CE et KL satisfont les quatre lois de l'espérance, l'identité de variance centrée, CE=H+KL\mathrm{CE} = H + \mathrm{KL}CE=H+KL, Gibbs KL≥0\mathrm{KL} \ge 0KL≥0, H=0H = 0H=0 sur une masse ponctuelle, variance nulle des constantes, et la décomposition biais–variance du risque d'ensemble (ponctuelle et sommée sur les entrées). Non prouvé : que le logarithme réel satisfait LawfulLog (analyse, hors du cours), que les programmes Float satisfont quoi que ce soit (ils arrondissent), et que les chiffres imprimés se reproduisent sur d'autres distributions au-delà de l'arrondi. Entre le théorème et l'expérience se tient un écart explicite et non refermé — cet écart est le sujet de l'analyse numérique, pas de ce cours.

Limites et variantes​

  • Finie est une vraie restriction. Les densités continues (la KL gaussienne du VAE, chapitre 11 ; l'entropie de politiques continues) exigent des intégrales ; rien ici ne s'y étend sans analyse. Les formules se transposent en remplaçant les sommes par des intégrales — pas les preuves.
  • Le logarithme est supposé, pas construit. LawfulLog isole exactement quelles propriétés de log⁡\loglog le chapitre utilise ; construire log⁡\loglog (séries, intégrales) et prouver les quatre lois est de l'analyse.
  • Changement de base exclu. Tout est en « unités naturelles » (nats) : log⁡\loglog base eee. Les bits (base 2) reformatent HHH et KL d'une constante ; les preuves sont sans base.
  • Float est le far west. Chaque loi utilisée ici tombe pour Float au dernier bit : (p⋅q)/p≠q(p \cdot q)/p \ne q(p⋅q)/p=q en général. C'est pourquoi les théorèmes portent sur Rat et la démo imprime l'écart au lieu de le cacher.
