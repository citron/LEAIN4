# Index of essential concepts

This page tells you which concepts are **mandatory** (you must understand them to follow the rest of the course) and where to find any concept. The definitions are in the [Glossary](glossary). Mandatory concepts are marked with ★.

## Mandatory concepts, chapter by chapter

Before moving on from a chapter, make sure you can explain each of these in your own words.

- **[Chapter 0 — Setup and a tour of Lean](ch00-setup)**: Lean, Type, Theorem, Proof versus test, Generic code (type class)
- **[Chapter 1 — The single neuron](ch01-neuron)**: Neuron, Weight, Bias, Activation function, Vector, Dot product, Linear
- **[Chapter 2 — The perceptron, XOR and the first AI winter](ch02-perceptron)**: Perceptron, Linearly separable, XOR, Perceptron learning rule
- **[Chapter 3 — The multi-layer perceptron](ch03-mlp)**: Layer, Hidden layer, MLP (multi-layer perceptron), Loss, Gradient descent, Learning rate, Chain rule
- **[Chapter 4 — Deep networks and automatic differentiation](ch04-autodiff)**: Derivative, Gradient, Automatic differentiation (autodiff), Backpropagation (reverse mode), Gradient check
- **[Chapter 5 — Losses, optimizers, regularisation and MNIST](ch05-training)**: Softmax, Cross-entropy, Overfitting, Regularisation (weight decay), Optimizer, SGD, Mini-batch and epoch, Test set
- **[Chapter 6 — Convolutional networks](ch06-cnn)**: Convolution, Kernel (filter), Weight sharing, CNN
- **[Chapter 7 — Recurrent networks](ch07-rnn)**: Recurrent neural network (RNN), Hidden state, Backpropagation through time (BPTT), Vanishing gradient, Exploding gradient
- **[Chapter 8 — LSTM and gated memory](ch08-lstm)**: LSTM, Gate
- **[Chapter 9 — Attention and the Transformer](ch09-transformer)**: Token and embedding, Attention, Query, key, value, Transformer, Residual connection, Positional encoding, Causal mask
- **[Chapter 10 — Autoencoders and the VAE](ch10-vae)**: Generative model, Latent variable, Latent space, Autoencoder, VAE, KL divergence, Reparameterisation trick
- **[Chapter 11 — GANs](ch11-gan)**: GAN, Generator and discriminator, Mode collapse
- **[Chapter 12 — Diffusion models](ch12-diffusion)**: Diffusion model, Forward process, Denoising network
- **[Chapter 13 — Reinforcement learning](ch13-rl)**: Reinforcement learning, Agent, environment, reward, Policy, Return and discount, Q-value, Policy gradient (REINFORCE)
- **[Chapter 14 — World models](ch14-world-models)**: World model, Imagination (dream), Compounding error
- **[Chapter 15 — JEPA](ch15-jepa)**: Representation (embedding space), JEPA, Collapse, Linear probe
